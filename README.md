# Animator

Animator is a browser-based drawing app built with Gleam for UC Berkeley CS 61A. Write a `draw` function to describe a drawing, then watch the browser animate its paths.

[Open Animator](https://zachcoder888.github.io/animator/)

## How to use it

1. Pick a drawing from the library or choose **New Drawing**.
2. Edit the code and watch the canvas update. The **Shape** slider adjusts drawings that use `shape_slider`.
3. Use **Speed** to change playback speed or play in reverse. Drag the timeline to inspect a frame, then press **Play** to resume or **Replay** to start over after playback finishes.

Drawings are saved in the current browser. This repository hosts the built web app for GitHub Pages.
